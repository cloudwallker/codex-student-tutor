# 工具验证说明

本文记录成品工具的验证范围与复现方式。

## 验证环境

| 项目 | 环境 |
| --- | --- |
| 操作系统 | Windows |
| Python | 3.9.25 |
| pypdf | 6.18.0 |
| 自动化测试 | 64 项：PDF 文字提取 22 项，本地学习档案 42 项 |

PDF 工具声明支持 Python 3.9+，依赖范围为 `pypdf>=5,<7`；以上是实际验证环境，不表示已测试全部系统或依赖版本。

## 成品工具

| 工具 | 用途 |
| --- | --- |
| [pdf_to_text.py](../tools/pdf_to_text.py) | 提取 PDF 已有文字层，按页读取，给出读取警示与截断续读位置 |
| [study_state.py](../tools/study_state.py) | 建立昵称档案、教材课程索引，保存作答证据，更新当前年级并保留历史 |
| [verify_bundle.py](../tools/verify_bundle.py) | 检查三份技能的脚本副本、相对引用和元数据，并在临时工作区验证完整工具流程 |

每份技能的 `scripts/` 包含独立可用的 PDF 和档案工具，与 `tools/` 中对应文件保持一致。

## 复现命令

在项目根目录、已安装 PDF 依赖的 Python 环境中运行：

```sh
python -m pip install -r tools/requirements.txt
python -B -m unittest discover -s tests -v
python -B tools/verify_bundle.py
```

测试使用合成 PDF、文字题和临时档案，不需要真实教材、学生信息或 API 密钥。

## 测试要点

[PDF 提取测试](../tests/test_pdf_to_text.py)共 22 项，检查文字层与中文字符、真实 PDF 页码、页数上限、长页与总输出截断、字符偏移续读，以及缺文件、伪 PDF、加密 PDF、无文字页和缺依赖时的明确失败行为。工具不会将无文字或稀疏文字页宣称为完整教材内容。

[本地档案测试](../tests/test_study_state.py)共 42 项，检查昵称与课程标识、学段内年级、跨学段补基础、升年级保留历史、课程合并、教材哈希、作答帮助程度、重试幂等、数据与日期校验、损坏文件保护、写入锁与原子写入失败后的数据保留。正确率不会自动变成掌握认证。

`verify_bundle.py` 对小学、初中、高中三份技能逐一检查脚本副本与可解析性、Markdown 相对链接、调用元数据，并运行 PDF 提取、建立档案、跨学段教材索引、重复作答保存、年级更新和续学读取。临时验证数据会在流程结束后清理。

## 结果的含义

64 项测试及三份技能的工具流程检查通过，支持上述脚本行为与打包一致性。它们不验证每次联网检索的可访问性、不替代新练习题的逐题求解，也不证明长期教学效果。第一版的 OCR、图像、音频和视频识别不在实现或验证范围内。
