## 可以怎样学习

- **围绕自己的教材。** 从一道题、粘贴的文字或教材 PDF 开始，按实际读到的内容与已学方法学习。
- **每次推进一小步。** 定位具体卡点，逐步加强提示，再换题检验独立应用；需要时可以直接要求完整解析。
- **研究题型后再练习。** Codex 实际联网搜索并打开来源核实，再编原创题或明确标注的改编题，出题后重新求解和检查。联网来源无法核实时，会明确标为根据教材编写的原创练习。
- **用证据衔接续学。** 本地保存教材位置、答案、思路、帮助程度和复习日期，不同学生按昵称分开记录。
- **补基础，保留历史。** 当前学生年级与所用教材年级分别记录，允许跨学段补基础；升年级或升学段时保留已有课程与作答。

## 三份技能

| 技能 | 适用学生 | 教学重点 |
| --- | --- | --- |
| [`cn-primary-tutor`](skills/cn-primary-tutor/SKILL.md) | 小学一至六年级 | 具体例子、读题、文字图示、算术思路与短步骤 |
| [`cn-junior-tutor`](skills/cn-junior-tutor/SKILL.md) | 初中七至九年级 | 概念关系、建模、规范步骤与材料证据 |
| [`cn-senior-tutor`](skills/cn-senior-tutor/SKILL.md) | 高中一至三年级 | 推导、综合应用、分类讨论、条件与边界 |

三份技能始终用中文辅导。学科策略覆盖语言、数学与自然科学、人文社会、信息科技/技术、艺术、体育与健康、劳动及综合实践，高中另含通用技术。范围由实际教材、选科与模块确定。开放题按任务与证据评价，接受有依据的不同答案；实践、音视频与图像课程在第一版按文字描述开展。

## 快速开始

### 1. 安装技能

把 `skills/` 中需要的完整技能目录复制到学习工作区的 `.agents/skills/`：

```text
<学习工作区>/
└── .agents/
    └── skills/
        ├── cn-primary-tutor/
        ├── cn-junior-tutor/
        └── cn-senior-tutor/
```

每份目录都是自包含的，`SKILL.md`、`agents/openai.yaml`、参考文件和脚本必须一起保留。也可以使用当前 Codex 环境已配置并能识别的个人技能目录。不要多处重复安装同名技能；没有出现在选择器中时，重启 Codex。参见[官方技能说明](https://learn.chatgpt.com/docs/build-skills)。

### 2. 准备 PDF 读取环境

使用 Python 3.9 或更新版本。在学习工作区运行，安装已放入其中的技能依赖：

```sh
python -m pip install -r ".agents/skills/cn-primary-tutor/scripts/requirements.txt"
```

三份技能的依赖相同，均为 `pypdf>=5,<7`。如果安装的是其他学段，或使用个人技能目录，将命令中的路径替换为安装后实际目录中的 `scripts/requirements.txt`。本地档案工具只用 Python 标准库；工具不会自动安装依赖。

### 3. 开始一课

在 Codex 打开自己的学习工作区，把教材 PDF 放入其中，提供可访问的附件，或直接粘贴本节文字。第一版使用 PDF 已有文字层；扫描页或缺失的配图需要用文字补充题干和关键条件。

按学段调用：

```text
使用 $cn-primary-tutor。我五年级，教材是“数学五年级下册.pdf”，从分数加法开始。请先看看我哪里不会，再逐步教我。
```

```text
使用 $cn-junior-tutor。我初二，读“数学八年级.pdf”中一次函数这一节，先诊断基础，再出题练习。
```

```text
使用 $cn-senior-tutor。我高二，学习“数学选择性必修.pdf”的导数章节。按教材方法辅导，最后给一道综合验证题。
```

以后可以说：“继续上次的学习”“换个讲法”“直接给我完整解析”“出题考我”“复习上次的错题”。默认昵称 ID 为 `student-1`；多人共用工作区时，每位学生使用不同昵称，例如 `learner-a`。昵称接受 ASCII 字母、数字、下划线和短横线。

## 本地学习记录

档案保存在当前学习工作区 `.student-tutor/learners/<昵称>/`，与技能安装目录分开：

| 记录 | 保存内容 |
| --- | --- |
| 教材索引 | 来源、可选 SHA-256、教材学段与年级、知识点、前置知识、实际 PDF 页码及读取状态 |
| 学习证据 | 原题、学生答案与思路、结果、帮助程度、反馈、有依据的错因及复习日期 |
| 当前档案 | 昵称、当前学段与年级；更新时保留旧课程与作答 |

独立完成、提示后完成和看过解析分别记录。得到帮助后答对，不会变成独立通过；工具不根据正确率自动认证掌握，而是通过不同形式的独立验证与后续复习继续积累证据。

记录不会自动同步到外部服务。实际教学时，相关教材文字与记录会用于当前 Codex 对话。复习日期用于续学选择题目，不会自动创建提醒或发送报告。

使用昵称，不提供真实姓名、学校或联系方式。仓库的 `.gitignore` 已排除 `.student-tutor/`；安装到已有项目时，将这条规则补入原有忽略文件，不覆盖其他规则。

## 第一版边界

- **只读 PDF 已有文字层。** 不进行 OCR、图像理解、手写、音频或视频识别。几何、电路、地图或实验条件缺失时，先补充文字，再判断唯一结论。
- **分批读取。** PDF 工具默认每次最多读取 12 页，PDF 页码从 1 开始，可能与课本印刷页码不同。长页截断会给出按字符偏移继续读取的提示。
- **核对异常文字。** 公式、表格与版面顺序可能需要确认；看到目录或提取到文字，不代表全部教材正文已读或已理解。
- **核实来源与答案。** 搜索摘要不等于已核实来源；改题后重新求解，考试专题结合相关地区与年份核实范围。

包内不含 API 密钥、模型权重、教材或题库正文。
