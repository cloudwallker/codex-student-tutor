# 初中全科策略

只读当前学科，依据实际教材、已学方法和学生尝试确定起点。七八九年级的进度由教材确认，初三专题再结合本地区中考要求。

| 学科 | 教学动作 | 练习与评价 |
| --- | --- | --- |
| 语文 | 字词/文言联系上下文；阅读找证据和表达作用；作文从立意、材料、结构到细节逐项修改 | 回应题意、引用准确、分析与证据对应；合理异解按文本依据评价，保留学生原意 |
| 数学 | 把题意转为未知量、关系式或证明；代数重视等价变形，几何区分条件和结论 | 设量→列式→求解→检验；证明每步有依据，缺图关系先补文字；不把数值猜测当证明 |
| 外语（英语等） | 在语境中解释词汇、语法与句式；阅读定位信息再推断，写作先按目的组织表达 | 意义、语境、语法和篇章；接受合理表达变体；没有音频输入就不评听力/发音 |
| 物理 | 现象→对象/过程→条件→物理关系；从文字建立受力、电路、运动等模型 | 单位、测量量、条件和数量级；电路缺连接信息不推断；实验变量、步骤和误差分别评价 |
| 化学 | 连接宏观现象、微观解释和符号表达；从反应条件到守恒再列式 | 元素/质量/电荷等实际适用守恒、化学式与配平、条件；缺装置/步骤先核对 |
| 生物学 | 用结构与功能、层次与过程解释，区分概念和相似术语 | 概念边界、过程因果、材料/实验数据证据；不要只用关键词命中判全对 |
| 历史 | 先时间地点与材料，再区分背景、原因、过程、影响 | 史实、材料证据与推理；区分史料原文和作者解读，不用空泛口号替代论证 |
| 地理 | 从位置、环境、过程和人地关系建立因果链 | 坐标/图例/比例尺缺失先补文字；结论须对应材料、单位与区域尺度 |
| 道德与法治 | 用概念解释真实情境，区分事实、价值判断与规则依据 | 问题识别、材料引用、依据和行为建议；当前政策规则用现行官方来源核实 |
| 信息科技 | 输入→处理→输出、算法与数据，用小例子演示流程 | 可执行步骤、边界输入和结果；未运行不声称代码通过；按学生已有环境处理 |
| 艺术、体育与健康 | 按教材维度解释结构、规则、鉴赏和训练常识，设计描述/观察任务 | 第一版只按文字证据反馈，不能据此认证声音、作品图像或动作姿势 |
| 劳动、综合实践 | 任务→方案→步骤→实际记录→反思 | 方案可行、过程证据、结果和反思；未完成的实践不代填成已完成 |

## 典型误概念与迁移

- 数学把去括号漏乘、等式变形不等价等定位到具体一步，用对应的小式子诊断，再回原题。
- 理科把条件改变导致规律不适用作为迁移题，不只是换数值；示范后让学生解释哪个条件重要。
- 阅读与人文让学生用一段材料支持自己的判断，区分“材料说了什么”和“我推断了什么”。

中考题型检索只筛选当前教材可覆盖的范围。对尚未学的知识可以给预告或补基础选择，不直接用高中工具替学生完成。
