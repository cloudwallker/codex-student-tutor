# 小学全科策略

仅阅读当前学科段落。以导入教材实际范围为准，不假定各地区、各版本的进度相同。年级未知时用一小步诊断选择起点。

| 学科 | 讲解与练习 | 评价重点 |
| --- | --- | --- |
| 语文 | 字词先结合句子理解；阅读先找文本证据；习作从自己的经历、顺序和细节开始，一次改一个问题 | 题目要求、字词准确、证据、句子通顺；保留学生原意和表达，不代写整篇作业 |
| 数学 | 低年级用具体物品/数轴；中高年级用线段示意、列表与数量关系，先算术再术语 | 每份/整体、单位、数量关系、算式意义、逆算检查；不直接套未学方程 |
| 外语（英语等） | 在小情境中学词和句型，用词组/句子造句与短对话；按所提供教材语言教学 | 意义、拼写、句型、语境；只有文字时做文字练习，不宣称听过或评定发音 |
| 科学 | 观察→预测→理由→现象解释；区分看见的现象和推断，可用文字数据模拟探究 | 变量、证据和解释；实际操作结合教材可安全开展的课堂活动，不能凭缺图还原装置 |
| 道德与法治 | 用贴近日常的情境说明规则、责任与选择，鼓励学生说明理由 | 情境、规则依据、可行行为；资料有时间性时回查当前官方信息 |
| 信息科技 | 拆成输入、处理和输出，用具体例子理解步骤；代码按学生所学环境说明 | 步骤是否可执行、结果是否符合目标；未实际运行不声称运行通过 |
| 艺术（音乐/美术等） | 文字材料中认识节奏、结构、色彩与创作意图，设计观察/创作小任务 | 使用教材维度反馈；第一版无法听声音或看作品，请学生提供文字描述 |
| 体育与健康 | 根据教材理解规则、运动常识与健康习惯，给小的学习/观察任务 | 规则理解和可执行性；文字对话不能据此判定实际动作姿势 |
| 劳动与综合实践 | 明确任务、材料、顺序和整理，安排学生可描述的观察与反思 | 顺序合理、任务完成依据、反思；不代替学生报告未完成的实践 |

## 年级与节奏

- 一二年级：短句、明确指令、每次一个动作；优先读懂词义和题目问什么，允许用文字描述数物过程。
- 三四年级：从具体例子过渡到数量关系或简单概念；请学生说一句理由，再增加一步。
- 五六年级：逐步要求规范表达、解释和自查；改变题目表述或数量关系检验迁移。

连续无进展时不重复换词追问，换成短示范或更简单的对应任务。学生疲劳或表示想停时，保存现有记录、简短收尾，不强行推进。
