# 高中全科策略

只读当前学科。先确认教材模块和已学方法，进入考试专题再结合地区、年份、卷别与选科。基础欠缺时补最小先修知识，不默认学生应当已经会。

| 学科 | 教学动作 | 练习与评价 |
| --- | --- | --- |
| 语文 | 文本精读与证据，古诗文结合语境和表达，写作从审题、论点、论证与结构到语言 | 引用准确、回应任务、分析与文本对应；作文一次处理关键问题，保留学生观点，不代写整篇作业 |
| 数学 | 目标→条件→表示/转化→推导→边界检查；区分局部与整体、充分与必要 | 定义域、参数分类、等价变形、单调区间/断点/端点、解的存在性；不同解法按正确性评价，不以方法相同判对错 |
| 外语（英语等） | 语境中解释语法，篇章结构与推断，写作目的、连贯和表达；按实际外语教材教学 | 文本证据、语义、语法与交际目标；接受合理表达变体；文字版不能认证听力或发音 |
| 物理 | 明确研究对象、过程和约束，再选择规律，联立前先说适用条件 | 受力/运动阶段、守恒适用条件、符号、单位、边界和数量级；装置/图线缺文字数据先核对 |
| 化学 | 宏观现象、微观模型、符号与定量联系；反应条件、结构、平衡/速率与守恒分别讨论 | 适用条件、守恒、化学式/结构、量纲及推理链；缺结构图/实验条件不能补造 |
| 生物学 | 结构功能、调控、遗传与生态层次联系，用材料或实验设计推理 | 概念边界、变量控制、数据与机制；区分教材结论和材料未支持的猜测 |
| 思想政治 | 概念→材料→推理→结论，区分事实、规范和价值判断，按题目任务组织表达 | 理论适用、材料对应、论证完整；有时间性的政策/规则回查现行官方材料 |
| 历史 | 时空框架、史料来源、观点、比较与因果，区分背景、原因和影响 | 史实准确、证据可靠、解释可辩护；不同历史解释依证据与范围评价 |
| 地理 | 从尺度、过程、区域与人地关系建立多因素因果链 | 坐标/图例/单位、时空尺度、材料证据；图形数据没有转为文字时不能拟造 |
| 信息技术 | 用数据、算法和系统结构解释问题，采用学生所学语言与环境 | 算法正确、边界输入、实际运行结果；未执行程序不声称验证通过 |
| 通用技术 | 需求、约束、方案比较、结构/系统/流程与评价 | 设计依据、可行性和权衡；以学生提供的文字结构和实际过程证据评价 |
| 艺术、体育与健康 | 教材中的鉴赏、结构、规则与健康知识，组织观察/反思任务 | 第一版按文字材料反馈，不能认证声音、作品图像或动作姿势 |
| 劳动、综合实践 | 规划、实施记录、分析与反思，关联学科知识 | 过程与结果证据、方法、限制与反思；未做实验/实践不代填数据或结论 |

## 综合与考试练习

- 综合题先确认单项知识可用，再增加连接；讲解时让学生自己选择连接点，而非把多个公式直接给全。
- 迁移题变化应影响思考，如改变条件、定义域、材料观点或过程阶段；每次重新核验答案。
- 高考题型以当前目标地区和已核实年份为依据；旧卷可参考结构，但不能默认为现行考试范围。
- 卷面表达按题目任务和可核实评分依据反馈；没有官方评分细则时明确这是教学评价，不虚构官方扣分。
