# 教材 PDF 文字处理

在首次导入教材、换章节、核对出处或补题目条件时读取。第一版只有文字提取；扫描 PDF、图片内文字、图形语义、手写和音频识别留给第二版。

## Codex 的实际读取路径

1. 使用学生给出的可访问文件路径；先使用 Codex 提供的附件实际路径或工作区 PDF 路径，再调用文字提取工具。普通文本读取不能代替 PDF 解析。学生没有路径时说：“把教材 PDF 放到当前学习文件夹，告诉我文件名和想学的章节。”如果部署已把上传文件转为可访问路径，就直接用该路径。
2. 用 本 `SKILL.md` 所在目录 解析 `scripts/pdf_to_text.py`，检查已安装 Python 和 pypdf。通过当前环境的 shell 工具运行，分别独立传递参数，准确引用有空格的路径，不把学生文字拼成 shell 代码。
3. 先处理封面、目录的少量页及目标章节。PDF 页码从 1 开始，表示文件中的第几页；印刷页码可能不同。学生说“课本第 20 页”时先定位对应 PDF 页，未知时核对页首标题，不猜偏移量。

```text
python "<本技能目录>/scripts/pdf_to_text.py" "<教材.pdf实际路径>" --pages "1-3,20-23"
```

尖括号为执行时替换的路径说明，不是可直接复制的命令。默认最多 12 页、每页最多 6000 字符、总正文最多 40000 字符；需要更多页时分批选择。长页和总输出截断会给出该页的下一段命令，例如 `--pages 20 --text-offset 6000`。偏移从 0 开始，只用于单页续读，按实际提示逐段读取到末尾；尚未输出的其它页再单独读取。缩小页范围不能恢复单页尾部。不把未取到的部分当作已读。

## 内容核对

- 根据封面和正文确认学科、年级、册别、出版社/版本、章节；缺失字段记为未知。不要凭文件名或目录推断未读正文。
- 从每段确认的正文提取知识点、前置知识、定义、教材方法和例题结构，保留 PDF 页码。目录可以建立 `unread` 节点，不能标 `verified`。
- 文字层中可能混有顺序错乱、缺字、公式上下标丢失。遇到异常字符、负号/分数/指数疑点或跨页条件，先提取相邻页，仍不清楚则请学生输入关键式子。
- 脚本“文字较少/没有可提取文字”只是读取警示，不证明那页必定是扫描页。页上可能只有插图，也可能是稀疏文字；不得补造内容。
- 能读到“见图”不代表已知图形。几何需文字确认点、线、平行垂直及角的位置；物理需电路连接、受力方向和装置；地理需坐标、比例尺、图例；化学需结构或实验步骤。
- 如果题意已能从文字独立确定，就正常辅导；只有缺失信息影响结论时才补问。可另出条件完整的纯文字题继续练习。

## 索引与材料变更

用 [本地记录](records.md) 保存当前教材课程与知识节点。正文已读取且关键内容完整为 `verified`；提取/公式有疑点为 `needs_confirmation`；仅见目录或尚未处理为 `unread`。记录只是定位依据，讲新内容时仍需回查相关原页。

更换教材版本或文件时建新课程 ID，避免把旧页码或旧进度误用到新教材。路径相同但学生替换了文件时也应重新核实来源，不能把“文件路径未变”当成内容未变。

## 失败后的学生话术

- 文件不可访问：“我还没有读到这份教材。告诉我当前学习文件夹中的文件名，或把这一节的文字贴过来。”
- 页上只有图像：“这一页没有提取到可用文字。第一版先按文字学习，你可以把题干和图里的关键条件打出来。”
- 环境缺依赖：“当前环境还不能提取 PDF 文字。先贴这一节文字就能继续学；PDF 读取需要在使用说明里完成一次环境准备。”

脚本不自动安装依赖，不上传教材到第三方转换服务，不修改原 PDF。
