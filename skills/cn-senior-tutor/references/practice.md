# 联网题型、练习与评价

新知识点首次练习、专题复习或学生要求出题时读取。先有已核实的教材内容，再研究题型；网络材料用于补充，不能把超纲方法覆盖教材范围。

## 检索与来源

1. 用学段、年级、实际知识点、版本（已知时）和题型构造查询；中高考专题再加地区/卷别及年份。不要把学生昵称、原作答或个人信息发进搜索查询。
2. 使用 Codex 当前可用的联网搜索工具，再打开相关页面正文。先核实 1—3 个相关来源，有足够题型证据就开始辅导，同一知识点可复用本次核实结果。
3. 优先教材出版机构、教育部门、教育考试院公开材料，其次可读的正规教学资料。校验题干完整、适用学段、使用方法、年份和答案；搜索摘要、营销标题和答案转载都不是充分依据。
4. 把匹配题型概括为考点、所需步骤、变化因素和常见误区，再生成新题。题目附简短标识：“原创练习，参考××题型”或“根据××改编”，并给核实的来源链接。
5. 联网无结果、工具不可用或正文访问失败时，明确说明“暂未核实联网题型，下面是根据教材内容编的原创题”，仍可继续教学；不能编造链接、年份、真题身份或联网记录。正常访问受限时不绕过登录/验证码。

题型优先级：当前知识点基础应用 → 常见误概念辨析 → 情境/条件迁移。根据学生已学内容选择，不把“更难”自动等同“更好”。

## 出题前的实际检查

- 明确题目目标、必要条件和评价依据，保证学生能从给定文字作答。配图缺失则转换成完整文字题，转换不了就换题。
- 独立解一次，再用代入、逆算、特殊值、单位/数量级或另一条推理路径复核。另一次模型重复生成同一答案不等于独立验证。
- 数学看解的存在性、唯一性和定义域；函数看断点、区间和端点；应用题看整数/非负/实际意义；理化看单位、守恒、实验条件和符号。
- 选择题保证所设唯一/多选规则一致，干扰项不是因题干歧义而也成立。改数字、条件后重新计算，不沿用原答案。
- 阅读、作文、史料、观点和鉴赏题先写评价维度：是否回应题目、证据准确、推理连贯、表达清楚。参考答案只是示例，合理异解按依据评价。
- 网络参考题自身有错误时，指出具体错误，修正或换题后再使用。不要以来源权威为理由保留错误条件。

## 给题与批改

默认每次一题，题目与答案分开；学生明确要求答案、完整解析或整套练习时按要求提供，不使用“永远不给答案”的硬规则。展示过答案就不把随后照着写记为独立完成。

学生作答后：先忠实读取答案和思路 → 分别评价结果/过程/表达 → 定位第一个关键错误 → 给最小必要提示或讲解 → 换一个有实质变化的验证题。正确答案配错误理由也要说明问题；没有过程时不猜错因，补问一个关键步骤。

“我懂了”是学生感受，不是掌握证据。独立答对本题只说明本题通过；用不同表述/条件的题和延后复习积累证据。批改按 [本地记录](records.md) 保存帮助程度、具体评价和错因，未证实的原因写待核实。
